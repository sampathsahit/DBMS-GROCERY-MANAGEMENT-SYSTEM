# Grocery Management System

## Introduction

The Grocery Management System is a web-based application developed using PHP, HTML, CSS, and MySQL.  
This project helps grocery store owners manage products, stock, customer orders, and billing efficiently.

The system reduces manual work and improves accuracy in maintaining grocery shop records.
This applications runs successfully only for local hosts .For that you should install XAMPP control panel (It runs a local MySQL server in background) 
It also provides Admin page which allows us to moniter login details , add items , modify prices , etc and we can manupulate the data in this application through SQL commands in this admin block

---

## Features

- Add new grocery products
- Update product details
- Delete products
- Manage stock quantity
- Customer order management
- Billing system
- Search products
- Simple and user-friendly interface

## Software Requirements

- XAMPP or WAMP Server

---

## Installation Steps

1. Install XAMPP/WAMP server.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL services.
4. Import the database file into phpMyAdmin.
5. Open the browser and run:
   http://localhost/project-folder-name
